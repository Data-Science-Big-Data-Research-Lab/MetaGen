# Notebooks

The notebooks of the documentation, which open in Google Colab from the links in its pages.

| Notebook | What it shows |
|---|---|
| `suc_p1.ipynb` | Solving use case: minimizing `x + 5` over an integer. |
| `suc_p2.ipynb` | Solving use case: minimizing `x^2` over a real. |
| `suc_p3.ipynb` | Solving use case: tuning a scikit-learn SGD regressor. |
| `suc_p4.ipynb` | Solving use case: tuning the architecture of a TensorFlow LSTM network. |
| `suc_tabu_search.ipynb` | Solving use case: the Rastrigin function with `TabuSearch`. |
| `duc_rs.ipynb` | Developing use case: writing a random search with MetaGen. |

Each one installs the package from PyPI in its first code cell.
